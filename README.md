# MangOS MainFrame NX-01

> A modular, local-first operating system written in Python.

MangOS MainFrame NX-01 is a personal cyberdeck operating system designed around a modular architecture. Instead of being a single application, MangOS is built as a collection of independent apps that run inside the same environment.

The project follows a **local-first philosophy**: every core feature works completely offline. Future modules may provide optional internet connectivity without making the operating system dependent on external services.

MangOS is currently under active development as the foundation for a portable cyberdeck powered by Python.
